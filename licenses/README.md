# Licence certificates

Proof of the rights this project relies on, kept with the code rather than in
somebody's inbox — a certificate nobody can find is the same as not having one.

| File | Covers |
|---|---|
| `dashspace-envato-elements.txt` | The DashSpace admin template, whose visual language informed `web/src/styles.css`. Envato Elements item licence `9FJS2WLKE3`, 22 September 2026. |

Two conditions in the Envato certificate are worth restating, because both are
about timing and neither is obvious later:

1. **The licence attaches to a completed End Product.** It is valid if the End
   Product is completed while the subscription is active; from then on it
   continues for the life of that End Product, subscription or not. So the
   certificate stays with the project permanently — do not remove it if the
   subscription lapses.
2. **It covers one specific project.** This application is that project. A
   second product built on the same design needs its own registered usage,
   obtained while a subscription is active.

The fonts (Cairo, Inter) carry the SIL Open Font License and need no
certificate; see `../NOTICE.md`.
